# ChatGPT Export PDF

> 🌏 **Traditional Chinese / English Bilingual**

A lightweight browser extension that adds an **Export PDF** button directly to the ChatGPT conversation interface, allowing you to export conversations as clean, printable PDF documents.

---

# 功能 Features

## 繁體中文
- 在 ChatGPT 對話畫面新增 **「匯出 PDF」** 按鈕。
- 一鍵匯出目前聊天內容。
- 保留標題、段落、程式碼區塊與基本格式。
- 支援繁體中文、英文及 Unicode 字元。
- 不需伺服器，完全在瀏覽器端執行。

## English
- Adds an **Export PDF** button to the ChatGPT chat interface.
- Export the current conversation with one click.
- Preserves headings, paragraphs, code blocks, and basic formatting.
- Full Unicode support (Traditional Chinese & English).
- Runs entirely in your browser. No backend required.

---

# 安裝 Installation

## Chrome / Edge

1. Download or clone this repository.
2. Open **chrome://extensions** (or **edge://extensions**).
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select this project folder.
6. Open ChatGPT and refresh the page.

---

# 使用方式 Usage

## 繁體中文
1. 開啟 ChatGPT。
2. 進入任何對話。
3. 點擊 **「匯出 PDF」**。
4. 系統將產生可列印的 PDF。

## English
1. Open ChatGPT.
2. Open any conversation.
3. Click **Export PDF**.
4. Save or print the generated PDF.
